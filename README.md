# 狙い目クイックチェック v1.1

機種名を入力し、以下3サイトの必要箇所を都度取得・表示する個人用Next.jsアプリです。

- DMMぱちタウン：機種詳細ページの `#anc-zone`
- ハイエナくん：通常公開記事の「まとめ」
- なな徹：機種解析ページから「天井の期待値や恩恵・ヤメ時と狙い目まとめ」へ移動し、非等価（5.6枚交換等）の期待値表

## v1.1変更点

- なな徹を追加
- 現在G数に対応する非等価期待値を表示
- カード型の自動要約表示を廃止
- 抽出元の表・見出し・箇条書きを直接表示

## 起動

```bash
npm install
npm run dev
```

## パスワード

環境変数 `APP_PASSWORD` を設定します。未設定時は `3131` です。


## v1.3

- なな徹の機種詳細ページ下部「攻略情報」にある「天井の期待値や恩恵・狙い目とヤメ時まとめ」を参照先として最優先
- 「狙い目／ヤメ時」の語順や中黒・空白の表記揺れに対応
- 設定判別、朝一、有利区間など他の関連記事を参照対象から除外


## v1.3 変更点

- 検索語に複数の機種がヒットした場合、正式機種名の候補を選択してから3サイトを参照します。
- 各サイトの結果タイトルは検索語ではなく、取得したページ上の機種名を表示します。
- なな徹は機種ページの「攻略情報」内にある「天井の期待値や発動ゲーム数・恩恵」リンクを取得します。
- 遷移先ページから、非等価・5.6枚交換を含む期待値金額表を抽出し、現在G数入力と連動します。
