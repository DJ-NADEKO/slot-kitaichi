# 狙い目クイックチェック v1.1

機種名を入力し、以下3サイトの必要箇所を都度取得・表示する個人用Next.jsアプリです。

- DMMぱちタウン：機種詳細ページの `#anc-zone`
- ハイエナくん：通常公開記事の「まとめ」
- なな徹：機種解析ページから「天井の期待値や恩恵・ヤメ時と狙い目まとめ」へ移動し、非等価（5.6枚交換等）の期待値表

## v1.1変更点

- なな徹を追加
- 現在G数に対応する非等価期待値を表示
- カード型の自動要約表示を廃止
- 抽出元の表・見出し・箇条書きを直接表示

## 起動

```bash
npm install
npm run dev
```

## パスワード

環境変数 `APP_PASSWORD` を設定します。未設定時は `3131` です。
