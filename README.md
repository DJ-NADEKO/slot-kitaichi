# 狙い目クイックチェック v1.0

機種名を入力し、DMMぱちタウンとハイエナくんの公開記事から指定箇所を都度参照する個人用Next.jsツールです。

## v1.0の主な機能

- パスワード認証
- 2サイト同時検索
- 検索結果の折りたたみ
- 抽出した狙い目・天井・リセット・ヤメ時のカード表示
- 現在G数入力による基準までの差分表示
- サイト間の簡易比較
- 最近の検索
- お気に入り
- スマホ向けUI

最近の検索とお気に入りだけはブラウザのlocalStorageに保存します。外部サイトの取得内容は保存しません。

## 起動

```bash
npm install
npm run dev
```

## 環境変数

```env
APP_PASSWORD=3131
```

Vercelでは Settings → Environment Variables に `APP_PASSWORD` を設定してください。
