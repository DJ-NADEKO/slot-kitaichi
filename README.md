# 機種情報クイック参照 v0.8

機種名を入力し、次の公開ページを都度検索・参照する個人用Next.jsツールです。取得内容は保存しません。

- DMMぱちタウン：各機種ページの「狙い目ゾーン・天井・ヤメ時」
- ハイエナくん：「ブログ会員限定記事」を除いた通常記事末尾の「まとめ」

## 起動

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いてください。

## 注意

対象サイトのHTML構造が変わると抽出できなくなる場合があります。会員限定記事へのログインや取得は行いません。


## v0.8 変更点
- DMMぱちタウンは `/machines/search?keyword=` を使って機種検索します。
- ハイエナくんの「まとめ」は、表・見出し・リスト等のHTML構造を保持して表示します。
- スクリプト、フォーム、イベント属性等は除去し、安全なタグだけを表示します。


## v0.8 DMM取得仕様

DMMぱちタウンは検索結果から機種詳細URLを特定し、詳細ページ本体の `h2#anc-zone` から次の `h2` 直前までを取得します。
表示元リンクは `/machines/{機種ID}#anc-zone` です。
セクション内にある、別ページへ遷移する画像バナー（「狙い目・ゾーン狙いまとめはコチラ！」等）と画像は表示対象から除外します。

## v0.9 認証設定

未認証時は `/login` に移動し、検索APIも利用できません。
ローカルでは未設定の場合 `3131` が使われます。本番ではVercelの Environment Variables に以下を登録してください。

```text
APP_PASSWORD=3131
```

環境変数を追加・変更した後は、Vercelで再デプロイしてください。
